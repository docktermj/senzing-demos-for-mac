Senzing Demo MacBook Checklist

Provision a factory-reset MacBook Pro for Senzing Bootcamp demos. Tick one column per machine.

MachinesSenzing-demo-01 · Senzing-demo-02
Accountssenzing (administrator) · demo (standard; all sign-ins and demos)
Repository~/senzing-demos-for-mac, linked from ~/Desktop/Senzing Demos
Install pageshub.senzing.com/bootcamp · hub.dockter.com/senzing-bootcamp-copilot-plugin-development/site

A. Before you start

0102AsStep
☐☐youHave the demo GitHub account ready, with read access to Senzing/senzing-bootcamp-copilot-plugin.
☐☐youHave sign-ins and plans ready: Claude (Max 5x or higher), ChatGPT (Pro), GitHub Copilot, Kiro (2000 credits or more).
☐☐youChoose passwords for senzing and demo. Do not use the same demo password on both machines.

B. macOS setup assistant

0102AsStep
☐☐—Create the administrator account senzing. Skip Apple ID / iCloud, or at least turn off iCloud Desktop & Documents.
☐☐senzingSystem Settings › General › Software Update: install all updates and restart.

C. Provision (administrator)

0102AsStep
☐☐senzingIn Terminal, download and run the provisioning script with this machine's name: 
curl -fsSLO https://raw.githubusercontent.com/docktermj/senzing-demos-for-mac/main/scripts/provision.sh
bash provision.sh --name Senzing-demo-01   # or Senzing-demo-02
Names the Mac; installs Homebrew, git, gh, Python, Java, Maven, jq, the Senzing SDK (answer y to the EULA) and the apps it can; keeps the Mac awake on power.
☐☐senzingWhen the script asks, enter the demo password you chose in section A. The script creates the standard user demo.
☐☐senzingInstall by hand any app the script lists at the end (Codex, GitHub Copilot, …). Drag each to /Applications.
☐☐senzingRe-run bash provision.sh. It should finish with nothing left to install by hand.

D. Demo user

0102AsStep
☐☐demoLog out, log in as demo, then in Terminal: 
git clone https://github.com/docktermj/senzing-demos-for-mac.git ~/senzing-demos-for-mac
bash ~/senzing-demos-for-mac/scripts/setup-user.sh
Adds Senzing Demos to the Desktop, checks the app links, sets the Senzing environment in ~/.zshrc and the Codex network setting.
☐☐demoOpen Senzing Demos on the Desktop and double-click each app: Claude, ChatGPT, Codex, GitHub Copilot, Kiro. Each one opens.
☐☐demoTurn on Do Not Disturb. Turn off screen lock and screen saver (System Settings › Lock Screen).

E. Sign in and install the bootcamp plugin (as demo)

0102AsStep
☐☐demoClaude: sign in. In Terminal, make an empty folder: mkdir ~/bootcamp-fresh-test. In Claude: Code › New, choose that folder, then + › Plugins › Manage plugins › Yours › Add › Add Marketplace: https://github.com/Senzing/senzing-bootcamp-claude-plugin › Sync › install for project (personal). Mode auto, model Sonnet 5.5, effort medium.
☐☐demoFresh bootcamp test: in Claude's chat, enter Start the bootcamp and let it run to graduation. This proves a brand-new bootcamp has everything it needs. If it needs software that is missing, install it with su - senzing -c 'brew install <package>' and add it to provision.sh.
While the bootcamp runs, set up the other apps:
☐☐demoCodex (ChatGPT): sign in. Plugins › Add › Add a marketplace: https://github.com/Senzing/senzing-bootcamp-chatgpt-plugin › Personal › Senzing Bootcamp › Install plugin. Model GPT-5.6 Terra, effort Medium.
☐☐demoGitHub Copilot: sign in with the demo GitHub account. Customize › + Add › Manage marketplaces: https://github.com/Senzing/senzing-bootcamp-copilot-plugin › Browse › All types › “bootcamp” › senzing-bootcamp › Install. Mode Interactive, Copilot Fusion, effort Standard.
☐☐demoKiro: sign in. Powers › Add Custom Power › Import power from GitHub: https://github.com/Senzing/senzing-bootcamp-kiro-power/tree/main/senzing-bootcamp (paste the full URL).

☐☐demoBanking KYC/KYB and AML (bootcamp-truthset-banking-kyc-kyb-aml): restores; docs/bootcamp_recap.pdf opens.

Always run the bootcamp as demo. Homebrew belongs to senzing, so typing its password at an install prompt does not help.
