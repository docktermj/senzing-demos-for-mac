# Data Source Locations

All three sources are synthetic: generated for this bootcamp by `src/scripts/generate_customer_data.java`
(seed `20261006`, reproducible). No real customer data is involved.

## Data Source 1: CRM_CONTACTS

- **Type**: CSV file
- **Location**: `data/raw/crm_contacts.csv`
- **Original Source**: Generated by the bootcamp (Customer 360 scenario)
- **Last Updated**: 2026-10-06
- **Record Count**: 4,000 records
- **Access Method**: Local file
- **Shape**: name in a single field; address in a single free-text field
- **Quality (generator self-check)**: 93.4 (target band >=80)

## Data Source 2: WEB_ORDERS

- **Type**: CSV file
- **Location**: `data/raw/web_orders.csv`
- **Original Source**: Generated by the bootcamp (Customer 360 scenario)
- **Last Updated**: 2026-10-06
- **Record Count**: 4,500 records
- **Access Method**: Local file
- **Shape**: name in two fields (first, last); address in four fields (street, city, state, zip)
- **Quality (generator self-check)**: 89.5 (target band >=80)

## Data Source 3: SUPPORT_TICKETS

- **Type**: JSON Lines file
- **Location**: `data/raw/support_tickets.jsonl`
- **Original Source**: Generated by the bootcamp (Customer 360 scenario)
- **Last Updated**: 2026-10-06
- **Record Count**: 1,500 records
- **Access Method**: Local file
- **Shape**: name in a single field; location as separate city and postal_code fields; many values missing
- **Quality (generator self-check)**: 75.5 (target band 70-79)

## Ground truth

`data/ground_truth/record_to_customer.csv` maps every record to the invented customer it describes
(7,000 customers in all). It exists so the resolution results can be checked later; it is
not an input to Senzing.
