# Data Source Locations

All three sources are **synthetic**: generated for this bootcamp scenario (Customer 360), not real customer data. The generator is `src/collect/generate_scenario_data.py` (seed recorded in `data/temp/generation_report.json`).

## Data Source 1: CRM_SYSTEM

- **Type**: CSV file
- **Location**: `data/raw/crm_system.csv`
- **Original Source**: generated by `src/collect/generate_scenario_data.py` (synthetic)
- **Last Updated**: 2026-11-09
- **Record Count**: 4,000 records
- **Access Method**: local file, regenerated on demand
- **Shape**: name as one joined field; address as free text; some missing email/phone; 300 campaign duplicates: the same customer entered again under another campaign, with its own record key

## Data Source 2: BILLING_SYSTEM

- **Type**: CSV file
- **Location**: `data/raw/billing_system-regenerated.csv` (current; regenerated with narrower gaps on the return from Data Quality, Mapping, and Transformation). Earlier versions kept: `data/raw/billing_system.csv` (as collected) and `data/raw/billing_system-improved.csv` (formats normalized)
- **Original Source**: generated by `src/collect/generate_scenario_data.py` (synthetic)
- **Last Updated**: 2026-11-09
- **Record Count**: 4,000 records
- **Access Method**: local file, regenerated on demand
- **Shape**: name in two parts (first/last); address parsed into components (street/city/state/zip); phone in inconsistent formats, some missing; 100 second billing accounts for customers who already have one, each with its own record key

## Data Source 3: SUPPORT_TICKETS

- **Type**: CSV file
- **Location**: `data/raw/support_tickets.csv`
- **Original Source**: generated by `src/collect/generate_scenario_data.py` (synthetic)
- **Last Updated**: 2026-11-09
- **Record Count**: 2,000 records
- **Access Method**: local file, regenerated on demand
- **Shape**: sparse: name and email only; occasional typos and inconsistent casing; 400 repeat tickets from customers who already filed one, each with its own record key

`data/ground_truth/scenario_ground_truth.csv` records which records are the same invented person. It is the scenario's answer key, kept for checking results later, and is not a source.
