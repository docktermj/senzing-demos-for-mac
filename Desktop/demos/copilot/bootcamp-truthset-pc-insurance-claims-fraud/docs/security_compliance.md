# Security and Compliance

- The collected files are from Senzing's synthetic Demo Truth Set; no real insurance claimant data was collected.
- Reviewer approval is still pending. Do not load these files until that approval is granted.
- `data/raw/*` is excluded from version control. Do not commit raw source files.
- If real personal data is introduced later, obtain the appropriate authorization and anonymize it for testing where practical.
- Do not paste raw records, personal data, credentials, or other sensitive values into prompts or tool arguments. Senzing's MCP privacy guidance says data files stay on the local machine, while tool arguments may be logged.
