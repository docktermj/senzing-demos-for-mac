# Data Handling and Security

The collected files are synthetic records from the Senzing Demo Truth Set; they are not
records about real customers. Raw files are stored under `data/raw/`, which is excluded by
`.gitignore`.

If real or otherwise sensitive data is introduced later, restrict access to the project,
avoid copying record values into chat or public artifacts, and anonymize data used for
testing where appropriate. Do not store credentials, license keys, or database passwords
in this document or in source control.
